# AtmoSync – Micro-Climate Arbitrage Analytics

## Project Overview

AtmoSync is a micro-climate monitoring and analytics project designed to monitor environmental conditions inside agricultural shipping containers.

The current implementation simulates IoT sensor readings for five avocado containers and streams the readings through Apache Kafka.

## Current Features

- IoT sensor data simulation
- Temperature monitoring
- Humidity monitoring
- Vibration monitoring
- Apache Kafka producer
- Apache Kafka consumer
- JSON-based sensor data streaming

## Technology Stack

- Python
- Apache Kafka
- Docker
- kafka-python

## Project Files

| File                | Description                             |
| ------------------- | --------------------------------------- |
| `simulator.py`      | Generates simulated IoT sensor readings |
| `kafka_producer.py` | Sends sensor readings to Kafka          |
| `kafka_consumer.py` | Receives readings from Kafka            |
| `readings.jsonl`    | Sample sensor readings                  |
| `requirements.txt`  | Python dependencies                     |

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/Shreyakolam1705/atmosync-micro-climate-arbitrage.git
cd atmosync-micro-climate-arbitrage
```

### 2. Switch to the Prakash branch

```bash
git switch prakash
```

### 3. Create a Python virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Start Apache Kafka

Make sure Docker Desktop is installed and running.

Start Kafka using:

```powershell
docker run -d --name atmosync-kafka -p 127.0.0.1:9092:9092 -e KAFKA_ADVERTISED_LISTENERS=PLAINTEXT://127.0.0.1:9092 apache/kafka:4.4.0
```
Wait until Kafka starts successfully.


### 6. Create the Kafka topic

```powershell
docker exec atmosync-kafka /opt/kafka/bin/kafka-topics.sh --create --topic sensor-readings --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
```

### 7. Run the Kafka consumer

Open the first terminal:

```powershell
python kafka_consumer.py
```

### 8. Run the Kafka producer

Open a second terminal:

```powershell
python kafka_producer.py
```

The consumer should receive the sensor readings generated by the producer.

## Sensor Parameters

- Container IDs: CONT-001 to CONT-004
- Commodity: Avocados
- Temperature: 4–12 °C
- Humidity: 80–95%
- Vibration: 0.1–2.0

*These are simulated readings and illustrative ranges, not validated agricultural safety thresholds.*
